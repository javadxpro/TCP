# 🎮 Gaming Voice Chat (چت و ویس روم گیمینگ)

یک وب‌اپلیکیشن چت صوتی و متنی سبک، سریع و بلادرنگ (Real-time) مخصوص گیمرها بر پایه **Cloudflare Workers**، **Durable Objects** و **WebRTC**.

این برنامه بدون نیاز به نصب هرگونه نرم‌افزار اضافی، اجازه می‌دهد شما و دوستانتان مستقیماً از داخل مرورگر در هنگام بازی کردن با کیفیت بالا و کمترین تاخیر (Peer-to-Peer) با یکدیگر صحبت کنید.

---

## ⚡ قابلیت‌های کلیدی

- **🌐 اتاق عمومی مشترک (Public Room):** به صورت پیش‌فرض تمام کاربران به یک اتاق عمومی مشترک متصل می‌شوند تا نیازی به ساخت و حفظ کدهای پیچیده اتاق نباشد.
- **🔒 امکان ساخت روم اختصاصی:** با وارد کردن نام دلخواه برای روم، می‌توانید یک فضای خصوصی فقط برای اسکواد یا تیم خود بسازید.
- **👤 ورود سریع بدون نام پیش‌فرض:** هر بازیکن باید نام گیمرتگ یا نام مستعار دلخواه خود را وارد کند تا هویت بازیکنان در بازی مشخص باشد.
- **🎙️ دو حالت صدای آزاد و کلید فشاری (Push-to-Talk):**
  - **حالت آزاد (Voice Activity):** میکروفون به صورت هوشمند باز است و می‌توانید با کلید `M` آن را مات (Mute) کنید.
  - **حالت فشاری (PTT):** با نگه‌داشتن کلید `Space` (یا کلید `V`) صحبت کنید؛ مخصوص زمانی که صدای اطراف یا کیبورد زیاد است.
- **✨ نشانگر صوتی کی داره حرف می‌زنه (Speaking Indicator):** نمایش هاله سبز رنگ نئونی دور کادر کاربری که در همان لحظه در حال صحبت است.
- **🔊 کنترل ولوم مجزا برای هر دوست:** اسلایدر اختصاصی برای کم و زیاد کردن صدای هر بازیکن به صورت جداگانه.
- **🔗 اشتراک‌گذاری سریع با یک کلیک:** دکمه کپی لینک مستقیم اتاق (`/?room=name`) جهت ارسال آسان در تلگرام یا دیسکورد.
- **📱 پشتیبانی کامل از PWA:** قابل نصب به صورت اپلیکیشن مستقل روی ویندوز، مک، اندروید و iOS.
- **🛡️ ایمن در برابر حملات XSS:** فیلتر و اعتبارسنجی تمام پیام‌های ارسالی و نام‌های کاربری.
- **🇮🇷 سه روش اتصال:** سرور، بدون سرور (MQTT عمومی) و هاست روی گوشی (سرور داخل اپ با ترمینال) — برای وقتی کلادفلر در دسترس نیست.
- **🔁 اتصال مجدد خودکار** پس از قطع سیگنالینگ.

## 🇮🇷 اتصال از داخل ایران (وقتی کلادفلر باز نمی‌شود)

دامنه‌ی `*.workers.dev` در ایران فیلتر است؛ برای همین دو روش «بدون دردسر» داخل خود برنامه اضافه شده که با دکمه‌های **روش اتصال** در صفحه‌ی ورود انتخاب می‌شوند:

| روش | چه کسی چه کاری می‌کند | نیاز |
|---|---|---|
| **☁️ بدون سرور** | همه فقط همین دکمه را می‌زنند و **یک نام اتاقِ خاص** وارد می‌کنند (نام اتاق مثل رمز است). فقط پیام‌های اتصال (SDP/ICE) از یک بروکر عمومی MQTT رد می‌شود و صدا مثل همیشه مستقیم P2P است. اگر بروکر اول باز نشد، خودکار بعدی امتحان می‌شود. | اینترنت |
| **📡 هاست روی گوشی من** | یک نفر در اپ اندروید «اجرا» را می‌زند؛ سرور سیگنالینگ داخل خود اپ بالا می‌آید و در ترمینال داخل برنامه آدرس `IP:PORT` را نشان می‌دهد (و کپی می‌کند). بقیه در حالت **🖥️ سرور** همان آدرس را می‌زنند (یا با مرورگر `http://IP:PORT` را باز می‌کنند). | هم‌شبکه بودن (وای‌فای مشترک یا هات‌اسپات هاست) |
| **🖥️ سرور** | همان حالت قبلی: کلادفلر، `server.js` روی ترمکس/کامپیوتر، یا آدرس گوشی هاست. | — |

### 👑 ادمین اتاق
ادمین خودکار تعیین می‌شود و نیازی به تنظیم ندارد: **هاستِ سرور داخل اپ**، وگرنه **اولین نفری که وارد اتاق شده**. اگر ادمین برود، نفر بعدی ادمین می‌شود. فقط ادمین بخش «👑 مدیریت اتاق» را می‌بیند:
- 🔇 ساکت کردن یک نفر یا همه (طرف می‌تواند دوباره میکروفونش را باز کند)
- ⛔ اخراج از اتاق
- 🔒 قفل اتاق (تازه‌واردها رد می‌شوند تا دوباره باز شود)

نکات:
- حالت پیش‌فرض برای کاربر جدید «بدون سرور» است؛ اسم شما هم برای دفعه‌ی بعد ذخیره می‌شود.
- در حالت «بدون سرور» می‌توانید بروکر دلخواه خودتان را هم بدهید (مثلاً یک Mosquitto روی سرور ایرانی با `wss://`).
- در حالت «هاست» اگر هاست هات‌اسپات روشن کند، IP او معمولاً `192.168.43.1` یا `192.168.x.1` است. برای اتصال از اینترنت باید روی مودم Port Forward کنید (با اینترنت سیم‌کارت معمولاً ممکن نیست).
- لینک دعوت (🔗 کپی لینک) حالت انتخاب‌شده را هم همراه خود می‌برد (`?mode=mqtt` یا `&server=ws://IP:PORT`).
- اگر وسط بازی اتصال سیگنالینگ قطع شود، برنامه خودش با فاصله‌ی افزایشی دوباره وصل می‌شود.

## 🛠️ راه‌اندازی و اجرای محلی (Local Development)

### پیش‌نیازها
- [Node.js](https://nodejs.org/) (نسخه ۱۸ به بالا)
- پکیج منیجر `npm`

### مراحل اجرا:
۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. اجرای سرور توسعه محلی کلادفلر با ریلود خودکار:
```bash
npm run dev
```
برنامه روی آدرس `http://localhost:8787` آماده استفاده خواهد بود.

۳. اجرای تست‌ها (و همگام‌سازی خودکار `index.html` با ورکر در `index.js`):
```bash
npm test
```

> `index.js` یک کپی از `index.html` را به‌صورت رشته در خود دارد. هر بار که `index.html` را تغییر می‌دهید `npm run sync:worker` (یا `npm test`/`npm run deploy`) آن را به‌روز می‌کند؛ `index.js` را دستی ویرایش نکنید.

## 🚀 دیپلوی روی GitHub Pages و Cloudflare Workers

### ۱. اجرای فرانت‌اند روی GitHub Pages
این مخزن به گونه‌ای تنظیم شده که هم به صورت کامل روی GitHub Pages و هم روی Cloudflare Workers اجرا شود:
- فایل `index.html` مستقیماً توسط **GitHub Pages** سرو می‌شود.
- در صورت باز کردن سایت از روی گیت‌هاب پیجز (`https://javadxpro.github.io/TCP/`)، برنامه به صورت خودکار به ورکر کلادفلر شما متصل می‌شود (یا می‌توانید از بخش «⚙️ تنظیمات سرور سیگنالینگ» آدرس دلخواه خود را وارد کنید).

### ۲. دیپلوی سرورلس روی Cloudflare Workers
برای فعال‌سازی بخش سرور و سیگنالینگ روی حساب کلادفلر:
```bash
# ورود به حساب کاربری
npx wrangler login

# انتشار پروژه
npm run deploy
```

> **نکته:** قابلیت **Durable Objects** در این پروژه ارتباط همزمان و پایداری سوکت‌ها را برای روم‌های صوتی فراهم می‌سازد.

## 📱 اپلیکیشن اندروید (APK)

پروژه با **Capacitor 7** به اپ اندروید تبدیل شده و یک **Foreground Service** (نوع `microphone`) دارد تا وقتی به بازی می‌روید میکروفون و اتصال WebRTC قطع نشود (نوتیفیکیشن «چت صوتی فعال است» نمایش داده می‌شود؛ WakeLock و WifiLock هم گرفته می‌شود).

- **دریافت APK:** در تب **Actions** گیت‌هاب، ورک‌فلو `Android APK` را باز کنید و آرتیفکت `TCP-Voice-apk` را دانلود کنید. با push یک تگ `v*` (مثلاً `v1.0.0`) فایل APK در بخش Releases هم منتشر می‌شود.
- **بیلد محلی:** `npm ci && npm run cap:sync && cd android && ./gradlew assembleDebug` (نیازمند JDK 21 و Android SDK).
- سرور پیش‌فرض داخل اپ `tcp.javadxpro.workers.dev` است و از دکمه تنظیمات سرور قابل تغییر است. برای سرور محلی بدون SSL آدرس را با `ws://IP:PORT` وارد کنید.
- پیشنهاد: در تنظیمات گوشی، بهینه‌سازی باتری را برای اپ «TCP Voice» خاموش کنید.

## 📡 اجرای سرور سیگنالینگ روی گوشی (Termux)

`server.js` بدون هیچ وابستگی (بدون `npm install`) اجرا می‌شود و پروتکلش دقیقاً مثل ورکر کلادفلر است. صفحه وب را هم روی `http://IP:PORT` سرو می‌کند.

```bash
pkg install -y nodejs git
git clone -b arena/01a0e304-tcp https://github.com/javadxpro/TCP.git
cd TCP
bash termux-server.sh        # یا: node server.js  (پورت پیش‌فرض 8080)
```

- آدرس (مثلاً `192.168.43.1:8080`) در ترمینال چاپ می‌شود؛ با نصب **Termux:API** (`pkg install termux-api`) خودکار در کلیپ‌بورد هم کپی می‌شود.
- دوستان آدرس را کپی کنند و اپ را باز کنند تا خودکار پر شود. در مرورگر هم می‌توانند مستقیم `http://IP:8080` را باز کنند.
- همه باید در **یک شبکه** باشند (هات‌اسپات گوشی میزبان یا یک وای‌فای). برای اینترنت عمومی از تونل (مثلاً `cloudflared tunnel --url http://localhost:8080`) استفاده کنید و آدرس `…trycloudflare.com` را بدهید.
- وضعیت سرور: `http://IP:8080/health`
- اگر پورت 8080 اشغال باشد، سرور خودش پورت بعدی (8081، …) را امتحان می‌کند و آدرس درست را نشان می‌دهد. اگر نسخه قبلی سرور هنوز روشن باشد، همین را اعلام می‌کند؛ برای بستنش: `pkill -f "node server.js"`
